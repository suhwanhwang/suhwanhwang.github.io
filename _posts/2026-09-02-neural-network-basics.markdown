트랜스포머(transformer) 논문("Attention Is All You Need")을 읽다 보면 임베딩 다음으로 신경망(neural network)이 나온다.
`xW₁ + b₁` 같은 식이 곳곳에 등장하는데, 막상 "신경망이 뭘 하는가"를 한마디로 말하기는 애매했다.
이 글은 그 식이 결국 곱셈과 덧셈일 뿐이라는 것을, 뉴런(neuron) 하나에서 시작해 층(layer)을 쌓는 데까지 정리한 것이다.

## 한 줄 정의

신경망은 **숫자 뭉치를 받아 다른 숫자 뭉치로 바꾸는 함수(function)**다.

```text
[0.9, 0.7, 0.0, 0.0]  →  신경망  →  [0.2, 0.8, 0.1]
```

"뇌를 모방했다"는 건 이름의 유래일 뿐, 실제로 하는 일은 곱셈과 덧셈이다.

## 뉴런 하나

> 입력들에 각각 가중치를 곱해서 더한다. 그리고 상수 하나를 더한다.

```text
입력:   x = [2.0, 3.0, 1.0]
가중치: w = [0.5, -1.0, 2.0]
편향:   b = 0.3

출력 = (2.0 × 0.5) + (3.0 × -1.0) + (1.0 × 2.0) + 0.3
     = 1.0 - 3.0 + 2.0 + 0.3 = 0.3
```

- **가중치(weight)**: 이 입력을 얼마나 중요하게 볼 것인가.
  음수면 반대 방향으로 작용, 큰 값이면 증폭.
- **편향(bias)**: 전체를 위아래로 밀어주는 조절값. `y = ax + b`의 `b`.

**`w`와 `b`가 학습으로 정해지는 값이다.** 처음엔 무작위다.

## 층 = 뉴런 여러 개

각 뉴런은 자기만의 가중치 세트를 갖는다.

```text
입력: [2.0, 3.0, 1.0]

뉴런 A: 가중치 [0.5, -1.0,  2.0], 편향 0.3  →  0.3
뉴런 B: 가중치 [1.0,  0.5, -0.5], 편향 0.0  →  3.0

결과: [0.3, 3.0]     (3차원 → 2차원)
```

## 행렬 곱

가중치를 표로 정리하면 이렇다.

```text
        입력1   입력2   입력3
뉴런A    0.5   -1.0    2.0
뉴런B    1.0    0.5   -0.5
```

이 표가 **행렬(matrix)**이다. 그리고 층의 계산 전체가 행렬 곱(matrix multiplication) 한 줄이 된다.

```text
출력 = W × x + b
```

**왜 행렬로 쓰나:** GPU가 행렬 곱에 최적화되어 있다.
for 루프로 뉴런을 하나씩 돌면 느리지만, 행렬 곱으로 표현하면
수천 개 곱셈이 동시에 처리된다. 딥러닝(deep learning)이 GPU를 쓰는 이유다.

```kotlin
// 개념적으로는: 뉴런마다 (가중치 · 입력) 내적에 편향을 더한다
for (neuron in neurons) {
    output[neuron] = weight[neuron] dot input + bias[neuron]
}

// 실제로는 (GPU 병렬 처리): 층 전체가 행렬 곱 한 번
output = W matmul input + b
```

논문의 `xW₁ + b₁` 같은 식은 전부 이것이다. 층 하나일 뿐이다.

## 문제: 층을 쌓아도 소용없다

```text
출력 = W₂ × (W₁ × x + b₁) + b₂
```

행렬 곱 두 번은 행렬 곱 한 번과 같다. `W₂ × W₁`을 미리 계산해
`W₃`라고 부르면 끝이다.

```text
출력 = W₃ × x + b₃
```

**층 100개를 쌓아도 층 1개와 동일하다.** 선형 변환(linear transformation)을 반복해도 선형 변환이다.
`y = 2x` 후 `y = 3y`는 결국 `y = 6x`인 것과 같다.

## 해결: 활성화 함수

층 사이에 비선형(nonlinear)적인 뭔가를 끼워 넣는다. 이걸 **활성화 함수(activation function)**라 하고,
가장 널리 쓰이는 건 **ReLU(Rectified Linear Unit)**다.

> 음수는 0으로, 양수는 그대로.

```text
ReLU(-3.0) = 0
ReLU(-0.1) = 0
ReLU( 2.5) = 2.5
```

코드로는 `max(0, x)` 한 줄이다. `max`는 행렬 곱으로 흡수할 수 없으므로
층이 합쳐지지 않는다. 그래서 쌓는 게 의미를 갖는다.

**논문 3.3절에 그대로 나온다.**

```text
FFN(x) = max(0, xW₁ + b₁)W₂ + b₂
         ↑
       이게 ReLU
```

층 → ReLU → 층. 딱 이 구조다.

**왜 이렇게 단순한 걸로 충분한가:** 꺾인 직선을 여러 개 이어 붙이면
어떤 곡선이든 근사(approximate)할 수 있다. ReLU 하나는 원점에서 한 번 꺾인 선이고,
수천 개 조합하면 아주 복잡한 모양이 만들어진다.

## 층을 쌓으면 생기는 일

**층마다 다루는 추상화(abstraction) 수준이 달라진다.**

이미지 인식 예시:

```text
1층: 밝기가 급변하는 곳 → 선분, 모서리
2층: 선분들의 조합     → 원, 각진 모양
3층: 모양들의 조합     → 눈, 코, 바퀴
4층: 부품들의 조합     → 얼굴, 자동차
```

아무도 "1층은 모서리를 찾아라"라고 지시하지 않았는데
학습하다 보면 자연스럽게 역할이 나뉜다.
언어에서도 아래층은 품사·어미 같은 표면적 패턴을,
위층으로 갈수록 의미와 논리를 다룬다.

**층을 쌓는다 = 단순한 변환을 여러 번 겹쳐 복잡한 변환을 만든다.**
이게 딥러닝의 "딥"이다.

## 전체 그림

```text
입력 벡터
   ↓
[층 1] W₁ 곱하고 b₁ 더하기
   ↓
[ReLU] 음수를 0으로
   ↓
[층 2] W₂ 곱하고 b₂ 더하기
   ↓
[ReLU]
   ↓
  ...
   ↓
출력 벡터
```

**모든 W와 b가 학습 대상이다.**
"파라미터(parameter) 수천억 개"란 이 W와 b의 개수를 말한다.

## 트랜스포머와의 연결

**Q, K, V를 만드는 것도 층이다.**

```text
Q = x × W_Q
K = x × W_K
V = x × W_V
```

토큰(token) 벡터에 행렬을 곱하는 것뿐이다. `W_Q`, `W_K`, `W_V`가 학습되는 가중치다.

**피드포워드 층(feed-forward layer)**은 512 → 2048 → 512, ReLU를 낀 2층짜리 신경망이다.

**출력층(output layer)**도 층 하나다. Figure 1 맨 위의 `Linear`가 512차원을
어휘(vocabulary) 크기(3~5만)로 펼치고, `Softmax`가 확률로 바꾼다.

즉 트랜스포머는 **여러 종류의 층을 특정 방식으로 배선한 구조물**이고,
부품 자체는 여기 나온 것 이상이 없다.

## 요약

| 개념 | 한 줄 |
|---|---|
| 뉴런 | 입력에 가중치 곱해 더하고 편향 더하기 |
| 가중치 W, 편향 b | 학습으로 정해지는 숫자들 = 파라미터 |
| 층 | 뉴런 여러 개. 행렬 곱 한 번 |
| 활성화 함수 | 층 사이의 비선형. ReLU = max(0, x) |
| 없으면? | 층을 쌓아도 한 층과 같음 |
| 깊게 쌓는 이유 | 층마다 추상화 수준이 달라짐 |
